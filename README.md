# Simulations Repository

A collection of quantitative, probabilistic, and physical simulations.

## Projects in this Repository

* **[TrueSimulation](./TrueSimulation)** — First-principles emergent financial market simulator built on continuous double auction order-book mechanics, Hawkes self-exciting processes, autonomous participant agents, and emergent Smart Money Concepts (SMC). Includes an interactive 60 FPS HTML5 Canvas trading terminal.
* **[monte-carlo](./monte-carlo)** — Monte Carlo probabilistic simulation experiments and computational models.
